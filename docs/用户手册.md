# 用户手册（中文）

## 1. 访问系统
- 打开浏览器访问：`http://localhost:3514/`

## 2. 主要功能

### 2.1 查看景点
- 地图上会显示所有景点标注（Marker）
- 点击标注可查看简介，并可直接设为起点或终点

### 2.2 选择起点/终点
- 左侧控制面板选择“起点”和“终点”
- 支持输入关键词搜索景点名称

### 2.3 开始规划
- 点击“开始规划”
- 系统会计算最短路径并在地图上画出路线
- 下方“路径结果”显示途经景点顺序与总距离

### 2.4 常用操作
- “交换”：交换起点与终点
- “清空”：清除起点/终点与规划结果

### 2.5 收藏路线
- 规划出满意路线后，在“路径结果”页签点击“收藏路线”
- 在弹窗中填写收藏名称（默认“起点 → 终点”），系统会保存名称、起点、终点、策略与完整路线节点
- 收藏保存在本机浏览器（localStorage），刷新页面后在“我的收藏”页签仍可查看
- 点击“加载”可将收藏路线恢复到地图与路径结果中（仅恢复展示，不重新计算）
- 点击“删除”会弹出确认框，确认后才会删除该收藏
- 收藏数据仅存于浏览器本地，不会写入后端，也不影响公共图数据（nodes.csv / edges.csv）

## 3. 常见问题

### 3.1 页面提示“加载节点失败”
- 检查后端是否启动：访问 `http://localhost:8514/api/health`
- 若未启动，建议执行：`docker compose up -d --build`

### 3.2 地图底图无法显示
- 底图来自 OpenStreetMap，离线或网络受限时可能无法加载
- 不影响路径规划与列表展示

## 4. 操作演练（合并）

### 4.1 一键启动
在项目根目录执行：
```bash
docker compose up -d --build
```

启动后访问：
- 前端：`http://localhost:3514/`
- 后端健康：`http://localhost:8514/api/health`

### 4.2 数据加载说明
- 启动后端时：
  - 若数据库无节点：从 `nodes.csv` 导入节点到 PostgreSQL
  - 读取 `edges.csv`：若存在则用其构图；否则按地理距离自动生成边

### 4.3 路径规划演练
1) 在左侧选择起点、终点（或在地图 Marker 弹窗中设置）
2) 点击“开始规划”
3) 在地图查看路线，在控制面板查看路径节点列表与每段距离

### 4.4 接口示例
```bash
curl -sS http://localhost:8514/api/nodes
curl -sS "http://localhost:8514/api/path?from=JIEFANGBEI&to=HONGYADONG"
```
