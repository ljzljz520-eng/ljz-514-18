# 用户手册（中文）

## 1. 访问系统
- 打开浏览器访问：`http://localhost:3514/`

## 2. 主要功能

### 2.1 查看景点
- 地图上会显示所有景点标注（Marker）
- 点击标注可查看简介，并可直接设为起点或终点

### 2.2 选择起点/终点
- 左侧控制面板选择“起点”和“终点”
- 支持输入关键词搜索景点名称

### 2.3 开始规划
- 选择“规划策略”（最短距离 / 最少经停）
- 点击“开始规划”
- 系统会计算路径并在地图上画出路线
- 下方“路径结果”显示途经景点顺序与总距离

### 2.4 收藏路线
- 规划出满意路线后，点击“路径结果”右上角的“收藏”
- 在弹窗中输入收藏名称（默认为“起点 → 终点”），确认后保存
- 收藏内容包含：名称、起点、终点、规划策略与完整路线节点
- 刷新页面后收藏仍在（优先保存在后端，后端不可用时自动保存在浏览器本地）

### 2.5 管理收藏
- “我的收藏”列表展示所有已收藏路线
- “载入”：把该收藏的路线恢复到地图与路径结果中
- “删除”：点击后需二次确认，确认后才会真正删除

### 2.6 常用操作
- “交换”：交换起点与终点
- “清空”：清除起点/终点与规划结果

## 3. 常见问题

### 3.1 页面提示“加载节点失败”
- 检查后端是否启动：访问 `http://localhost:8514/api/health`
- 若未启动，建议执行：`docker compose up -d --build`

### 3.2 地图底图无法显示
- 底图来自 OpenStreetMap，离线或网络受限时可能无法加载
- 不影响路径规划与列表展示

## 4. 操作演练（合并）

### 4.1 一键启动
在项目根目录执行：
```bash
docker compose up -d --build
```

启动后访问：
- 前端：`http://localhost:3514/`
- 后端健康：`http://localhost:8514/api/health`

### 4.2 数据加载说明
- 启动后端时：
  - 若数据库无节点：从 `nodes.csv` 导入节点到 PostgreSQL
  - 读取 `edges.csv`：若存在则用其构图；否则按地理距离自动生成边

### 4.3 路径规划演练
1) 在左侧选择起点、终点（或在地图 Marker 弹窗中设置）
2) 点击“开始规划”
3) 在地图查看路线，在控制面板查看路径节点列表与每段距离

### 4.4 接口示例
```bash
curl -sS http://localhost:8514/api/nodes
curl -sS "http://localhost:8514/api/path?from=JIEFANGBEI&to=HONGYADONG&strategy=distance"

# 路线收藏
curl -sS http://localhost:8514/api/favorites
curl -sS -X POST http://localhost:8514/api/favorites \
  -H "Content-Type: application/json" \
  -d '{"name":"解放碑到洪崖洞","startId":"JIEFANGBEI","endId":"HONGYADONG","strategy":"distance","totalDistanceMeters":812.5,"pathNodeIds":["JIEFANGBEI","HONGYADONG"],"pathNodes":[],"segmentDistanceMeters":[812.5]}'
curl -sS -X DELETE http://localhost:8514/api/favorites/<id>
```
